## 🎨 Adding New Screenshots
When capturing updated screenshots for documentation or release notes:
- Maintain a consistent viewport aspect ratio (16:9 or 16:10).
- Use dark or clean neutral backgrounds.
- Compress PNG images with `pngquant` or export as modern WebP/SVG before committing.
